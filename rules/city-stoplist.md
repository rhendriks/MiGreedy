# City stoplist

**Format: token list** (see [README](README.md#token-list)).

Words used by operators that happen to be city names.
These words are skipped to avoid inferring false locations.

Keep entries lowercase.

```text
master server backend customer managed cache share micro hosts redstone datum recursive
primary secondary public private global local anycast unicast resolver gateway cluster
control controlplane origin mobile split orange reading nice bath union victoria temple
florida turbo central pandi station harbour harbor bridge
```
