# Code aliases

**Format: table** — columns `code`, `iata`, `notes` (notes optional).

Site codes used by operators that are not the 'standardized' IATA code of the airport.

| code | iata | notes                                      |
|------|------|--------------------------------------------|
| FFM  | FRA  | old railway code for Frankfurt am Main     |
| TKY  | TYO  | common Tokyo abbreviation                  |
| TOK  | TYO  | common Tokyo abbreviation                  |
| LDN  | LON  | London                                     |
| SGP  | SIN  | Singapore                                  |
