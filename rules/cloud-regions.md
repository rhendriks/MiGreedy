# Cloud regions

**Format: table** — columns `region`, `city`, `country`, `notes` (notes optional).

Cloud region codes that appear in server names
(`ip-10-33-1-177.ap-southeast-1.compute.internal`),
mapped to the city of the region.

Currently, [AWS regions](https://aws.amazon.com/about-aws/global-infrastructure/regions_az/) only.
